## 建議世界實測順序

使用同一份世界備份及測試角色，先在普通角色 Token，再在未連結角色的 Token 重複：

1. 普通武器傷害、偷襲、火／霜巨人各自扣次數；取消、重擊各測一次。
2. 靈能打擊及普通奪命之手：來源與扣除量正確；最後 1 次可用，0 次不可用。
3. 活殺自在：自身次數與活動連結外部資源各測一次，切換普通／活殺自在確認只扣所選來源。
4. 魔焰專家／塑能增幅：單顆、兩顆、混合骰面及最後一顆；同時勾兩項不應超額花費。
5. 開著傷害視窗時由角色卡花掉資源，再重開／重新繪製並提交，確認畫面與附傷一致。
6. 快捷新增填錯數量、返回改名，再前進修正，確認能完成儲存。

待實測後再進行：整套資源架構整合、GM 集中處理跨瀏覽器競爭、世界與個人自訂衝突策略及設定介面拆分。本版不宣稱已解決跨瀏覽器原子性或所有其他模組的重複扣除。

# v0.7.0：分開管理預設與自訂，補上重複附傷防護

設定 → 模組設定 → 額外傷害選項 → 編輯額外傷害：

- **預設資料**：勾選啟用項目，內建資料由模組管理。
- **自訂資料**：保留文字格式，可自行新增、改名、調整公式與偵測名稱。清空此區不會停用預設。
- 自訂資料對應到內建能力時，自訂優先，預設不再同時加入；設定頁會顯示提醒。
- 完全重複的自訂列在擲骰時只保留一份。不同能力即使同骰式同屬性，仍可分別使用。
- 直接擲能力本身的傷害時，不再追加同能力（閃電發射器保留明確手動追加功能）。
- 原傷害 options.flavor 明確標示相同能力名稱時，停用該加傷選項。
- 神聖打擊／牧師強力施法、原初打擊／德魯伊強力施法，兩組各自互斥。
- 無來源名稱的原傷害、武器內建附傷、Active Effect 或其他模組純數字加值，無法可靠自動判斷；仍需確認避免重複。

**升級保留資料**：主要 GM 進世界後自動分離舊清單。修改過的預設（含名稱、骰式、類型、別名）移入自訂，對應內建預設停用。刪除過的預設維持停用；完全空白清單維持停用。原 entries 設定保留為升級前備份，不再用於日常編輯。

檢查結果：內建45項無完全重複。61項 JavaScript 邏輯／模擬介面測試通過；未在使用者實際 FVTT／Midi-QOL 世界測試，也未讀取使用者世界中的 Active Effects 或傷害公式。

| 霜之寒冷 | 1d6 寒冷 | Giant Ancestry (Frost)／Frost's Chill | 對應特性 1 次 |

火、霜各用自己特性本身的使用次數。兩者同時存在時皆可選，同時使用各扣 1 次。選項顯示剩餘次數，耗盡、未設定次數、無修改權限或找到多個對應特性時停用。

取消視窗或僅預覽不扣次數。擲骰前檢查餘額，擲骰完成後再次檢查並更新 system.uses.spent，完成後才繼續送出聊天訊息。重擊仍只扣 1 次。直接擲該特性本身傷害時，不列出同一特性的加傷。恢復次數沿用特性既有的休息／恢復設定。

## 自訂

設定 → 模組設定 → 額外傷害選擇 → 編輯額外傷害（GM）。每行格式：

```
顯示名稱 | 公式 | 傷害類型 | 能力名稱;其他別名
自製聖焰 | 1d8 | radiant | 聖焰之力
偷襲 | sneak | inherit | 偷襲;Sneak Attack
```

省略第四欄時，預設項目使用內建別名，自訂項目使用顯示名稱。sneak 依遊蕩者職業等級計算；inherit 跟隨第一筆傷害類型。火、霜預設名稱或別名啟用次數連動；一般自訂項目尚無資源消耗欄位。

只搜尋目前擲骰角色的 spell / feat 名稱與 identifier，不搜尋描述、種族名稱或合輯。比對忽略大小寫、空白與標點，支援括號內翻譯。沒有遊蕩者職業資料時隱藏自動偷襲。

## 限制與驗證

玩家仍須判斷命中、武器條件、專注、目標印記、每回合限制等；已由其他效果加入的傷害請勿重複勾選。霜之寒冷的減速不自動套用。略過原生傷害視窗不提供選項。

消耗僅支援特性物品本身的 uses，不支援活動專屬次數或指向其他物品的共用資源。同一瀏覽器內同角色多個視窗依序處理；不同玩家或 GM 同時操作同角色不保證跨用戶鎖定，請避免同時扣同一資源。聊天訊息發送失敗不會退還已消耗次數。

26 項 Node 測試通過，涵蓋火霜獨立扣次數、同時選取、取消、重擊、餘額不足、寫入失敗、同瀏覽器並行擲骰與名稱比對。尚未在實際 Foundry 世界及 Midi-QOL 組合中驗證，請先用測試角色確認 UI 與角色卡同步。

0.3.0 新增火霜次數連動；修正純標點別名誤配及冒號子特性誤認為偷襲。額外傷害列的原生臨時加值欄位仍不生效，請在模組設定調整公式。

## 0.4.0：至聖斬與魔能重斬

角色擁有至聖斬／Divine Smite 法術或特性時，顯示至聖斬；擁有魔能重斬／Eldritch Smite 時顯示魔能重斬。更新後由 active GM 自動加入這兩項預設，保留自訂內容與已刪除的舊預設；完全清空的清單仍停用。

- 至聖斬採 2024 公式：所選環級 + 1 顆 d8 光耀傷害；勾選「目標為邪魔 Fiend／亡靈 Undead」再加 1d8。例：三環為 4d8，符合目標條件則 5d8。可選一般法術位或契約位。
- 魔能重斬：所選契約位環級 + 1 顆 d8 力場傷害，依法只允許契約魔法法術位。角色只有一種契約位環級時，選單只會有該環級；一般法術位不列入。
- 選單顯示剩餘數量。勾選能力並完成擲骰才扣所選資源；取消不扣，重擊仍只扣一個位。同時使用兩種重斬須消耗兩個法術位，若共用契約池會合併檢查數量。
- 目標加傷由玩家勾選確認，不自動讀取目標。未自動檢查命中、近戰／契約武器、附贈動作、每回合一次、每回合法術位施法限制；也不自動使目標伏地。不處理聖武士的免費施放次數。請勿先用原生能力扣位後又勾選同一能力。
- 直接擲重斬法術／特性本身傷害時，不再列出同一能力。若想沿用選單，自訂骰式欄必須填 divine 或 eldritch；填固定骰式則視為普通加傷。

自訂格式：

```
至聖斬 | divine | radiant | 至聖斬;Divine Smite
魔能重斬 | eldritch | force | 魔能重斬;Eldritch Smite
```

26 項自動測試通過。包含升環、特殊目標、雙重斬共用資源、取消、並行、資源更新失敗等。尚未在實際 Foundry／Midi-QOL 驗證。跨用戶同時操作仍無鎖定；混合血統與重斬需要分別更新角色與特性，若後者失敗會嘗試退還法術位，無法保證跨文件交易；出錯請檢查資源。

規則參照：[Divine Smite](https://www.dndbeyond.com/spells/2618833-divine-smite)、[Warlock / Eldritch Smite](https://www.dndbeyond.com/classes/2190885-warlock)。

## 0.5.0：遊俠加傷與祕法槍械

依使用者提供的能力規則加入五項預設：

| 選項 | 公式代號 | 傷害／消耗 |
|---|---|---|
| 恐懼打擊（妖精漫遊者） | fey | 遊俠 11 級前 1d4，之後 1d6 心靈 |
| 恐懼打擊（幽域追獵者） | gloom | 2d6 心靈，扣對應特性 1 次 |
| 巨像屠夫 | colossus | 1d8，沿用第一筆傷害類型 |
| 極地打擊 | polar | 遊俠 11 級前 1d4，之後 1d6 寒冷 |
| 祕法槍械 | firearm | 1d8，沿用第一筆傷害類型；僅法術傷害顯示 |

仍須角色擁有對應能力，不能只有子職。英文名稱或 identifier 的 Dreadful Strikes（複數）判為妖精漫遊者；Dreadful Strike（單數）判為幽域追獵者。中文同名時以角色卡的 subclass 物品名稱／identifier 判斷 Fey Wanderer／妖精漫遊者 或 Gloom Stalker／幽域追獵者。只有中文且無法判斷，或兩個子職同時存在時，停用選項並提示補上英文名稱／識別碼。若兩個能力都有清楚英文名稱，能各自獨立顯示。

幽域追獵者需先在特性上設定使用次數上限為感知調整值（最低 1），並設定長休恢復全部；模組沿用設定，不自動修改上限與恢復方式。未設定時停用並提示。妖精與極地版本需要角色卡的遊俠 class 等級資料，不以總等級計算。

每回合一次／每目標每回合一次不自動追蹤。玩家需確認武器命中、巨像屠夫目標生命未滿，以及祕法槍械確實作為奇械師法術法器且只加到一次傷害骰。祕法槍械只做法術來源過濾，不自動判斷施法職業或使用哪個法器；多種傷害時目前固定沿用第一筆傷害類型。

GM 進入世界會補入五項預設；保留原有自訂內容及已刪除的舊預設，完全清空的清單仍維持停用。35 項測試通過，尚未在實際 Foundry／Midi-QOL 環境驗證新項目。
